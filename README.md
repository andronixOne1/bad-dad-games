# Bad Dad Games 🕹️

> **GOOD GAMES. BAD MANNERS.**  
> Memorable characters, and instant entertainment.

A fast, responsive web application showcase and playable demo portal for Bad Dad Games.

## 🚀 Live on Render
This project is configured for one-click deployment on [Render](https://render.com) using the included `render.yaml` Static Site blueprint.

### Project Structure
- `index.html` - Main landing page with responsive hero, custom wave divider, and game cards.
- `styles.css` - Custom styling, particle animations, and game components.
- `app.js` - Interactive navigation, synthesized Web Audio SFX, and playable in-browser mini-game sandboxes:
  - 🥚 **Plinko Koko**: Real-time canvas physics rainbow egg drop.
  - 🌿 **Weed Bush**: Multiplier minefield sweeper.
  - 🎯 **Bad Darts**: Bullseye precision challenge.
- `assets/` - Extracted high-resolution graphics, logos, and game cards.
- `render.yaml` - Static site configuration for Render.
